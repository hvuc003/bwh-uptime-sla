## 搬瓦工 uptime 保障是什么？

**Uptime guarantee（在线时间保证）**，说白了就是服务等级协议（SLA）：商家承诺你的 VPS 在某段时间内有多少比例是正常运行的，达不到就赔。

计算公式很简单：**在线率 = 总在线时间 ÷ 总时间 × 100%**。

搬瓦工目前有两档承诺：

- **99.9% uptime**：每月允许宕机约 43 分钟，适用于常规套餐（KVM、CN2 GIA-E 等）
- **99.99% uptime**：每月允许宕机约 4.5 分钟，专属于 E-Commerce SLA Plan（DC5 机房）

99.9% 听起来差不多，实际用起来，多数时间几个月都不出一次问题。根据搬瓦工官方 Knowledge Base 的表述，他们已经长期维持了不低于 99.9% 的在线率。服务器状态页面 bwhstatus.com 实时对外公开，出了问题会第一时间更新进度。

## 搬瓦工 uptime 保障：宕机了怎么赔？

这部分只适用于购买了 E-Commerce SLA Plan（DC5 机房）的用户。

赔偿流程分三步：

1. **确认宕机超过 4.5 分钟**（270 秒）。可以通过 bwhstatus.com 或自己的监控工具记录。
2. **登录搬瓦工后台，提交 Support Ticket（工单）申请**。注意，系统不会自动赔偿，必须主动申请。
3. **等待审核**，通过后账户获得对应时长的服务积分（Service Credit）。

赔偿标准如下（宕机时长对应补偿时长）：

- 宕机 10 分钟以内 → 补偿 3 天
- 宕机 30 分钟以内 → 补偿 7 天
- 宕机 2 小时以内 → 补偿 14 天
- 宕机超过 12 小时 → 补偿 30 天（上限）

只要宕机超过 5 分钟，直接送 3 天时长——这在 VPS 行业里属于相当高的赔付标准。

### 哪些情况不赔？

下面这些属于免责条款，不计入宕机时间：

- 提前 24 小时公告的计划内维护
- 用户自己把防火墙配错、SSH 搞挂
- 因流量超限或 CPU 占用过高被临时暂停
- VPS 遭受 DDoS 攻击进入黑洞路由
- IP 被封（不属于商家故障）

## FAQ：关于搬瓦工 uptime 保障的常见问题

**Q：搬瓦工普通套餐宕机了可以申请赔偿吗？**

不行。SLA 赔偿协议目前只适用于明确标注了"Service Level Agreement"的 SLA Plan（即 DC5 机房的 E-Commerce SLA 系列）。普通 KVM、CN2 GIA-E 套餐没有书面赔偿条款，但搬瓦工长期维持 99.9% 以上的实际在线率，历史口碑相当稳。

**Q：SLA 赔偿是自动到账吗？还是需要申请？**

必须主动申请。系统不会自动发放。宕机事件发生后，登录后台提交工单，附上宕机时间段，等待官方审核，审核通过后以服务积分形式（延长使用时长）发放。

**Q：IP 被封算 uptime 违约吗？**

不算。IP 被封属于免责条款范围，不计入宕机时间，无法申请 SLA 赔偿。SLA 套餐的"每两周免费换 IP"政策是专门为此设计的补偿手段——IP 被封换一个就好，成本为零。

**Q：DC5 SLA 机房可以迁移到其他机房吗？**

目前不支持。SLA 套餐固定在洛杉矶 DC5 机房，无法一键切换到 DC6、DC9、软银等其他机房。如果你需要多机房灵活切换，CN2 GIA-E 常规套餐是更好的选择。

**Q：搬瓦工支持哪些付款方式？**

支付宝、PayPal、信用卡均支持。不做自动续费扣款，每次需手动续费。使用优惠码购买后，续费也按优惠价计算，循环有效。
